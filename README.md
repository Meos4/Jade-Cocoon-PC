A PC port of Jade Cocoon that reproduces the **US release (NTSC-U,
SLUS-00854)** and stays faithful to its code.

The game's code was reverse engineered and rewritten in its original language, to match the original. It runs natively on your computer, without an emulator.

The game will keep receiving updates after release, with new content, new maps and more added over time.

If you’d like to discuss it and see the project’s progress, you can join the Discord! https://discord.gg/RA7hmWSCWd

## Features

The port also comes with a whole set of mods, all optional from the game's own Options menu. Some bring back **beta and prototype content**,
the game as it was before release. Others dig up **unused content** that
stayed on the disc without ever being seen. The rest make the game nicer to
play: quality of life, fixes for bugs that shipped with the original, and options to tweak its **difficulty**.

### Platforms
- **Windows**
- **Linux**
